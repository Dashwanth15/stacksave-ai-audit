WHY THIS APPROACH?
──────────────────

❌ Cannot test locally:
   - 12/13 providers fail locally (403 blocks, timeouts)
   - Official pages may block non-GitHub IPs
   - Results don't prove production behavior

✅ Must test in GitHub Actions:
   - Same environment as production sync
   - Has Playwright + Chromium installed
   - Different IP range (AWS) may allow access
   - Results prove real production behavior

✅ Dry-run is safe:
   - Read-only access to MongoDB
   - Simulates changes in memory
   - Zero database modifications
   - Can run unlimited times
